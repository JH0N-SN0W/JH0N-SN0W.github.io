微软推出 Microsoft-Decision-1：面向路由与分类的决策评分模型，称比 GPT-6 Sol 快约 35 倍

2026-10-09 · Microsoft Command Line · Microsoft Learn

微软 Office of the CTO 软件工程副总裁 Achint Srivastava 2026 年 10 月 9 日在 Command Line 博客发文，正式介绍 Microsoft-Decision-1：面向路由、分类、优先级、校验与工作流控制的决策评分模型，已在 Microsoft Foundry 与 OpenRouter 上线。文中强调，决策模型与生成式大语言模型不同，目标是给出软件可立刻执行的结构化输出，而不是长篇文本推理。

官方称该模型在约 15 万题、36 项对训练保持盲测的基准对比中准确率最高；速度方面写明，在其基准中它是测得最快的：比亚军 H2O-Lightning-4B v1.1 快 2.5 倍，比 GPT-6 Sol 快约 35 倍。文中另称 P50 延迟约为 GPT-6 Sol 的约 35 倍快。微软说明模型基于对 Qwen3.5-9B 的后训练做单次前向决策打分，并计划随后换用包括 Microsoft AI（MAI）与 OpenAI 在内的其他骨干。

输入 token 定价为每百万 0.042 美元，输出 token 免费。

给定固定选项时，Microsoft-Decision-1 为每个选项返回校准后的概率，支持是非、多选、评分，以及对 AI 应答与智能体动作的量规打分。微软还报告：对同一请求做八种扰动时，平均仅 1.3% 会改判，且选项描述改写或选项顺序打乱时零翻转；在 11 项基准共 5250 条有害内容、越狱与提示注入请求上测试了拒识与可用性。定价一节写明：输入 token 定价为每百万 0.042 美元，输出 token 免费。Microsoft Learn 文档说明可在 Foundry 目录部署该模型，并通过决策 API 调用；权重不开放下载。本稿数字均以微软官方帖与 Learn 文档为准。
