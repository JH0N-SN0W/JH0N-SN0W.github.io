DeepSeek Harness v0.2 推出官方桌面应用，开源智能体框架支持 Mac 与 Windows

2026-10-03 · MarkTechPost · DeepSeek

MarkTechPost 2026 年 10 月 3 日报道，DeepSeek 为其开源智能体框架 DeepSeek Harness（dsh）发布官方桌面应用，随 v0.2 预览版推出，提供 macOS（Apple 芯片）与 Windows（64 位）安装包；也可以运行 npx @deepseek-ai/dsh web 使用网页界面。DeepSeek 提醒，后续版本仍会有不兼容的改动。

v0.2 预装常用办公与开发工具，新增插件管理页、右侧文件与代码差异预览，支持上传文档、表格或 PDF 生成图表和幻灯片，并带有可定时运行提示词的 Automation Task 插件。桌面版内置 dsh 命令，不再需要另装 Node.js 或 pnpm，可用 DeepSeek 账号登录或填入 API key。

模型适配器、工具注册表和智能体循环本身都是插件，任何一层都可以替换。

报道称，dsh 于 2026 年 8 月以 MIT 许可开源，构建在 Cordis 之上，奉行「everything is a plugin」：模型适配器、工具注册表和智能体循环本身都是插件，任何一层都可以替换。它不绑定 DeepSeek 模型，也支持兼容 OpenAI 接口的第三方服务；仓库已超过 24 万星。本稿只转述已核对的公开报道。
