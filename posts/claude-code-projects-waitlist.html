ClaudeDevs：Claude Code Projects 已向等候名单上全部 Pro / Max 用户开放公测

2026-10-09 · ClaudeDevs · Anthropic（Claude）

Anthropic 面向开发者的账号 ClaudeDevs 于 2026 年 10 月 9 日发帖称：「We just let in every Pro and Max user from the Claude Code Projects waitlist!」并附四分钟上手演示。同串后续说明：Projects 仍处于公测；尚未报名者可加入等候名单，公司会在产能允许时继续放行更多 Pro / Max 用户。

Anthropic 在 Claude 资源中心文章《Projects redesigned: from folder to conversation》中介绍，更新后的 Projects 以会话而非文件夹组织工作：用户描述目标后，由 Claude 划定范围、委派任务、协调并行线程、审阅产出并汇总结果；可在离开电脑后继续推进，也可从手机跟进。文章举例：可设定降低结账 p75 延迟等目标，让 Claude 在并行线程中剖析接口、试验优化并开出多个 PR。

每个线程是独立 Git 分支上的 Claude Code 云会话，协调器负责组织工作，代码重叠仍按普通 PR 合并冲突处理。

官方说明：每个线程是独立 Git 分支上的 Claude Code 云会话，协调器负责组织工作，代码重叠仍按普通 PR 合并冲突处理；线程还可再拆成子智能体、循环与工作流。项目共享记忆与资料库，便于长周期智能体式任务。文章称更新版 Projects 先向部分使用 Claude Code 云会话、且网页或桌面尚无旧项目的 Claude Pro / Max 订阅者开放公测，随后一周向更多同计划用户扩展；全 Claude 产品线以及 Team / Enterprise 的更新版项目将更晚推出。因可同时跑多个完整会话，用量可能更快触顶。本稿只转述 ClaudeDevs 帖文与 Anthropic 官方产品说明。
