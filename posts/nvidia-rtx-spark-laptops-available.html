英伟达 RTX Spark 笔记本全球开售：单芯片集成 Blackwell GPU 与 Grace CPU，最高 128GB 统一内存，起价 2599 美元

2026-10-16 · NVIDIA Newsroom

英伟达 10 月 16 日宣布 RTX Spark 笔记本电脑即日起在全球开售，首批机型来自华硕、戴尔、惠普、联想、微软和微星，包括华硕 ProArt P14/P16、戴尔 XPS 16、惠普 OmniBook Ultra 与 OmniBook X 14、联想 Yoga Pro 9n、微软 Surface Laptop Ultra，以及微星 Prestige N16 Flip AI+ 和 Prestige N16，起价 2599 美元，具体价格与配置因地区而异。

据英伟达介绍，RTX Spark 是一颗把 Blackwell RTX GPU 与 Grace CPU 集成在一起的超级芯片，提供最高 128GB 统一内存和最高 1 petaflop 的 FP4 AI 算力，联发科参与了定制 CPU 的设计。英伟达称，共享内存让大型创作项目和本地 AI 模型可以同时高效运行。黄仁勋在新闻稿中说，RTX Spark 把英伟达 AI、RTX 图形和 CUDA 与 Windows 结合在一台电脑里，用于创作、游戏和运行个人 AI 智能体。

「共享内存让大型创作项目和本地 AI 模型可以同时高效运行」

软件方面，英伟达称用户无需命令行即可通过引导式安装使用 GitHub Copilot、Hermes、OpenClaw、Perplexity 等智能体；740 亿参数模型 Nemotron 3.5 Bolt 74B-A9B 24GB 可在支持的 RTX Spark 配置上本地运行，OpenShell 安全运行时与微软 Execution Containers 用于控制智能体权限。英伟达与微软还为 Windows on Arm 准备了首个 PyTorch-CUDA 版本，并称已支持前 15,000 个 Python 包中的 97%。
