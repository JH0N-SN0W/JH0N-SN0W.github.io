OpenAI：Daybreak Red 登陆 AWS GovCloud（美东）；获批客户可通过 Bedrock 使用 GPT-5.6 Cyber

2026-11-04 · OpenAI

OpenAI 于 2026 年 11 月 4 日宣布，在既有 Amazon Bedrock 上 Daybreak 模型可用性的基础上，通过 Daybreak Red 将 GPT-5.6 Cyber 提供给 AWS GovCloud（US-East）中获批的政府客户。公司称，此举让政府安全团队可在其支持关键任务的 AWS 环境中，使用面向授权漏洞研究、利用验证与安全测试的专用网络安全模型。

把前沿网络安全能力，接到政府团队已在用的安全与治理流程里

据介绍，GPT-5.6 Cyber 可协助防御方梳理复杂软件弱点、在受控环境中复现漏洞并拟定缓解措施；合格安全从业者仍应在落地前人工审阅发现与拟议修复。Daybreak Red 对通过身份核验的防御方在授权网络安全任务上给予更大操作空间，同时配套更强身份验证、监控与访问控制。

OpenAI 强调：在 Amazon Bedrock 上的 Daybreak Red，推理数据不用于训练模型，客户也无需将 Daybreak Red 数据分享给 OpenAI。访问需同时完成 OpenAI Daybreak Red 审批与 AWS 开通；Daybreak 审批不会自动开通 AWS 上的模型访问，需与 AWS 客户团队配合启用。
