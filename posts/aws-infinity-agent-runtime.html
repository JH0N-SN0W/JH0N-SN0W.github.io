AWS 开源 Infinity：面向极端并发的智能体运行时，称 8GB 可驻留约 7.5 万个空闲智能体

2026-10-23 · AWS Open Source Blog · GitHub（hydro-project/infinity）

AWS 开源博客于 2026 年 10 月 23 日由 Shadaj Laddad 撰文，宣布以 Apache 2.0 许可发布研究项目 Infinity，作为 AWS 与加州大学伯克利分校合作的 Hydro 项目一部分。Infinity 把智能体工具调用当作无栈协程的挂起点：调用工具时派发调用、持久化对话并挂起智能体；工具结果到达后再从存储恢复。目标是让智能体在等待构建、审批或外部事件时不再长期占用进程与内存。

「With Infinity, concurrent agents are extremely lightweight. For example, we can fit 75,000 concurrent agents in the 8 GB of a Raspberry Pi 5.」

官方基准称，在模拟模型下约每空闲智能体占用 100 KB 常驻内存，按此速率约 7.5 万个智能体可放入 8 GB（树莓派 5 内存量级）。挂起后无运行中的任务，因此也可部署在无服务器平台：参考架构使用 SQS FIFO、Lambda、Aurora DSQL 与 DynamoDB，工具调用等待期间无需保持函数运行。异步事件通过「合成工具调用」（synthetic tool calls）注入对话，使模型 API 仍看到合规的工具调用/结果结构；父子智能体通信亦复用同一机制。

代码仓库为 github.com/hydro-project/infinity。AWS 强调这是早期研究发布，欢迎反馈；文中亦列出事件交错推理、调度策略、对话树压缩与事件真实性等未决问题。内存与并发数字为 AWS 自测基准，第三方复现情况本稿未核对。
