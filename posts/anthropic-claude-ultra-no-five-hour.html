Claude Ultra（原 Max 20x）验证账号取消五小时会话限额；周额度仍为 Pro 的 10 倍；月费 200 美元

2026-11-02 前后 · Claude Help Center（两文均标 Updated this week）

Claude 帮助中心本周更新的《What is the Ultra plan?》说明：原 Max 20x 现更名为 Ultra，现有 Max 20x 订户自动迁入且价格不变。Ultra 面向个人消费者，网页订阅月费 200 美元（移动端定价可能因平台而异）；每周用量为 Pro 计划的 10 倍，并含 Claude Code 统一订阅、优先体验新模型/功能，以及每月 API 积分等。

验证 Ultra 账号无五小时限；Settings > Usage 无 Current session 条即已验证

对已验证（verified）的 Ultra 账号，不再适用五小时会话限额，可在周额度内按自己的节奏使用。未验证账号仍有临时五小时限制；Anthropic 称会依据账户与支付历史等因素自动验证，验证后自动解除，用户无需额外操作。结账时的手机号验证是独立步骤，不等于解除该五小时限。可在 Settings > Usage 查看：若看不到「Current session」进度条，即表示账号已验证。

另据《How do usage and length limits work?》，付费计划通常有每五小时重置的会话限额与每周限额；Ultra 验证账号免除五小时限，但仍有跨模型的周额度，并对 Fable 另设单独周限。用量在 claude.ai、Claude Code、Claude Desktop 等产品面合计计算。帮助中心亦提醒可能另行施加周/月或模型/功能层面的容量管理限制。
