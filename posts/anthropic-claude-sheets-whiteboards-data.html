模型与产品

Anthropic 推出 Claude Whiteboards 与 Claude Sheets（beta），并将 Claude Dashboards 正式更名为 Claude Data：面向所有付费方案；Whiteboards 为与 Claude 共用的协作白板，Sheets 为由 Claude 协同生成并编辑的电子表格，Data 增加认证查询与实时分享等能力

2026-11-10 · Anthropic / Claude

Anthropic 于 2026 年 11 月 10 日在 Claude 官网宣布，推出 Claude Whiteboards 与 Claude Sheets 的测试版（beta），同时将此前的 Claude Dashboards 正式开放，并更名为 Claude Data。公告写明，这三项功能面向所有付费方案。Whiteboards 被描述为团队与 Claude 共同头脑风暴的共享白板；Sheets 是由 Claude 与用户一起构建并编辑的电子表格；Claude Data 则增加了数据叙事、认证查询（certified queries）与实时分享等能力。

现在，你的文档、白板、表格和仪表盘可以留在 Claude 里，供团队继续一起编辑。

公告解释，过去把 Claude 的产出转到其他工具后，Claude 往往无法继续跟进后续修改；现在文档、白板、表格和仪表盘可以留在 Claude 里，供团队继续一起编辑，也可以在准备就绪后导入合作伙伴的工具。Whiteboards 方面，用户可与 Claude 口头梳理尚不成形的计划，由 Claude 生成带负责人和日期的时间线看板，并支持实时协作；例如在复盘会上，参与者可各自添加笔记，由 Claude 按主题归类并起草行动项。用户还可以框选看板的一部分向 Claude 提问，完成讨论后把看板转成文档或演示文稿，或导入 Lucid、Miro，以及 Zoho 的 Vani 等工具。Sheets 方面，Claude 可根据提示生成带工作表、公式、格式和下拉菜单的电子表格，并在单元格中编辑、标出每处改动以便追踪；表格可与团队共享。公告同时写明，目前表格功能仍较简单，正在继续增强；若需完整 Excel 功能，可导出为 .xlsx 或 CSV，或使用 Claude for Excel，也可在 Airtable、Asana、monday.com 与 Smartsheet 等合作工具中继续处理。

Claude Data 由 10 月上线测试版的 Claude Dashboards 转正并更名，公告称更名是因为企业使用数据的方式已超出仪表盘。认证查询与实时分享目前仍为测试版。能力包括：数据团队可认证供全员使用的指标查询，基于这些指标的图表会带「已认证」标记；可在 Claude Data 中起草数据叙事或解说视频，供审阅后再分享；借助实时分享，同事打开共享仪表盘时可看到经批准查询的最新结果，但不能用分享者的权限另跑其他查询；并支持设计系统、按仪表盘设置缓存与刷新节奏，以及变更追踪与回滚。数据连接器方面，公告提到 Amazon Redshift、BigQuery 与 ClickHouse 等；Data 的合作伙伴包括 Amplitude、Mixpanel、Omni、PostHog 与 Sigma。同日，交互式连接器可在对话旁以完整应用或全屏打开，公告举例包括 Adobe、Atlassian、Box 与 Notion。上述功能可在网页、桌面和移动端使用；Claude Data 需要数据连接器（如数据仓库或 CRM）。管理设置方面：Team 方案三项默认开启；Enterprise 方案中，Whiteboards 与 Sheets 默认关闭，Claude Data 将于 2026 年 11 月 19 日默认开启，均可在组织设置的 Artifacts 中随时更改。
