谷歌云推出 Agent Compute Engine：硬件隔离 microVM 托管智能体，源自 Gemini 内部基建；客户预览将至

2026-10-22 · Google Cloud · The New Stack · SiliconANGLE

据 The New Stack、SiliconANGLE 等报道，谷歌云于 10 月 22 日在 Linux Foundation 的 AGNTCon+MCPCon（圣何塞）宣布 Agent Compute Engine：把支撑 Gemini 等智能体的内部算力基建产品化，为每个智能体会话提供硬件隔离的单租户 microVM（自有客户内核与 root），兼顾容器式启动速度与沙箱隔离；客户预览预计今年晚些时候开放。官方博文亦介绍该服务与扩展的智能体治理能力。

每个智能体会话一台硬件隔离的 microVM——源自 Gemini 内部基建。

技术说明称：传统 VM 启停慢，普通容器又难满足需要内核级控制的编码/助手类智能体。Agent Compute Engine 用 Cloud Hypervisor，并由 Titan/Titanium IPU 等硬件信任根支撑；沙箱内不存放长期密钥，身份为短时会话级，出站经外部代理，凭证在沙箱外由 Agent Gateway 注入。智能体空闲时对 microVM 做检查点，几乎不占活动资源，待下一轮工具调用再恢复——针对「大半时间在等模型或用户」的特点。

谷歌同时强调面向 GKE 的开源 Agent Substrate：在 Agent Sandbox 上加轻量控制面，可对空闲智能体快照并回收算力，称密度可达传统方案约 10 倍；在 20 万智能体基准中处理约 500 次激活/秒，挂起/恢复低于约 0.5 秒。Substrate 可与 Claude Code 等 harness 配合。定价、区域与正式 GA 日期尚未在报道中给出。
