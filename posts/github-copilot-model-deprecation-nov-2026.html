GitHub 将于 11 月 16 日下线部分 Copilot 模型：含 Claude Opus 4.8、Opus 5 与 GPT-5.6 Terra

2026-10-15 · GitHub Changelog

GitHub 于 10 月 15 日在 Changelog 宣布，将在 2026 年 11 月 16 日于所有 GitHub Copilot 体验（含 Copilot Chat、inline edits、ask 与 agent 模式以及代码补全）中下线下列模型：Claude Opus 4.8、Claude Opus 5，以及 GPT-5.6 Terra。建议替代分别为 Claude Opus 5.5，以及 GPT-6.1 Sol 或 GPT-6 Luna。

脚注说明：Claude Opus 4.8 将继续向购买年度计划的个人 GitHub Copilot 订阅用户提供，以便其仍保有 Opus 选项；对该类客户，Opus 4.8 的下线不适用。GitHub 请用户在此日期前将工作流与集成切换到受支持模型。

「We will deprecate the following models across all GitHub Copilot experiences … on November 16th, 2026」

在默认模型启用策略下，建议的替代模型会为 Copilot Enterprise 与 Copilot Business 客户自动启用，除非管理员关闭了全局默认或显式禁用了该模型。若已关闭全局默认，可通过 Copilot 设置中的模型策略启用替代模型。启用后，用户可在支持的 Copilot 体验中的模型选择器看到这些模型。下线后无需额外操作移除旧模型；企业客户如有疑问可联系客户团队。
