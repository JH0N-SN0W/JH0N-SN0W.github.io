Anthropic 将 Agent Skills 开放标准捐给 Linux 基金会旗下 Agentic AI Foundation

2026-10-22 · Anthropic · Linux Foundation / AAIF

Anthropic 于 2026 年 10 月 22 日宣布，将 Agent Skills 开放标准捐给 Linux 基金会旗下的 Agentic AI Foundation（AAIF）。Agent Skills 以含 SKILL.md 的文件夹形式，向智能体提供可复用的任务流程、脚本与参考材料。公司称自 2025 年 12 月公开该标准以来，已有逾 70 个智能体平台接入，包括 ChatGPT、Cursor、GitHub Copilot 与 VS Code；迄今约有 100 万个技能发布、近 2.8 亿次安装。

「We’re committed to keeping Agent Skills open, community-driven, and vendor-neutral.」

捐赠范围包括 Agent Skills 名称与标识、GitHub 组织以及 agentskills.io 域名。使用或贡献该标准不必加入 AAIF。Anthropic 称 AAIF 由其与 Block、OpenAI 共同发起，此前亦接收了 Model Context Protocol（MCP）。维护由 Anthropic、Google、OpenAI 等公司工程师以个人身份参与，David Soria Parra 与 Mahesh Murag 任首席维护者。

Linux 基金会同日称，AAIF 宣布 Agent Skills、Open Responses、OpenEnv 与 OpenSandbox 等新项目。Anthropic 还提出后续路线图方向，包括版本化发布、正式提案流程，以及技能编写与安装的安全指引。规范见 agentskills.io，讨论在 GitHub 与项目 Discord 进行。
