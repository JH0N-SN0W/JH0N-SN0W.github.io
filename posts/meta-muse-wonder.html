Meta 发布 Muse Wonder / Muse Wonder Full：面向个人与职场智能体的前沿模型

2026-10-12 · Meta AI Research · Meta 开发者博客

Meta 研究博客 2026 年 10 月 12 日介绍 Muse Wonder 系列：Muse Wonder 与 Muse Wonder Full。公司称二者是目前最强模型，在个人与职场智能体任务上达到前沿水平，并强调 Active Memory（跨对话记住并主动取回相关信息）与 Active Focus（遇阻时换路径、恢复错误、必要时澄清并在重要动作前确认）。Muse Wonder 已通过 Meta Model API 与 Muse Code 提供；Muse Wonder Full 面向 Muse Code 订阅用户。

「Muse Wonder brings together Active Memory and Active Focus to keep track of what matters to you and work diligently toward what you want to accomplish.」

开发者侧博文写明 Muse Wonder 在 Muse Code 与 Meta Model API 的标价为每百万 token 输入 4 美元、输出 20 美元；Muse Wonder Full 随 Muse Code 的 Power / Maximum Usage 订阅提供，Maximum Usage 额度约为 Everyday Usage 的 80 倍。模型面向法律、金融、健康等专业场景与长程编程；安全方面称在 CBRN 与网络滥用防护上加强，同时按 Meta Superintelligence Scaling Framework 保留防御性网络能力。完整安全评估报告称将另行发布。训练算力据称来自其吉瓦级 Prometheus 数据中心。
