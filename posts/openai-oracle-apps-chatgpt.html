OpenAI 扩大与甲骨文合作：把 Oracle 应用与数据接入 ChatGPT；甲骨文推出 AI Workspace、AI Security Mesh 与 SMB 套装

2026-10-27 · OpenAI · Oracle

OpenAI 于 2026 年 10 月 27 日发文称，与甲骨文扩大合作：把 Oracle 应用与企业数据接入 ChatGPT，并用 OpenAI 模型与产品支撑甲骨文新产品。OpenAI 称此举建立在既有 API、ChatGPT Work 与 Codex 商业关系之上；甲骨文报告约 13 万活跃 ChatGPT 用户、逾 9.5 万活跃 Codex 用户。

甲骨文正在开发 Oracle AI Workspace，目标是在 ChatGPT 内通过与 Oracle 应用及数据的集成，让员工用自然语言完成经权限与审批约束的业务流程。同期宣布的还有：Oracle AI Security Mesh（用 OpenAI 网络模型协助发现并修复应用与基础设施漏洞，由甲骨文管理测试基础设施）、面向中小企业的 Oracle AI SMB Bundle（组合 ChatGPT Business、Codex、Oracle 应用与周期性 OCI 积分），以及帮助团队用 Codex 等工具构建并部署应用的 Oracle App Composer。

美国甲骨文客户可通过 Oracle Marketplace，用既有采购流程与符合条件的 Universal Credits 购买 OpenAI API、Codex 与 ChatGPT Work

甲骨文同日在 Oracle AI World（拉斯维加斯）发布会中强调「agent-ready enterprise」愿景，称 AI Workspace 拟连接 Fusion Applications、NetSuite、Oracle AI Database、OCI 等。OpenAI 与甲骨文均强调访问须受组织权限与审批治理。
