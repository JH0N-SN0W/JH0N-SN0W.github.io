OpenAI 为 GPT-6.1 Sol 推出 Ultrafast：称最高约 8 倍标准速度；API、Codex、ChatGPT Work 与 AWS Bedrock 上线

2026-10-08 · OpenAI 开发者社区 · AWS

OpenAI 开发者社区 2026 年 10 月 8 日公告称，GPT-6.1 Sol 的 Ultrafast 模式即日起在 API、Codex 与 ChatGPT Work 推出，宣传「接近 Astra 的智能、最高可达 Sol 标准模式约 8 倍的速度」。请求仍用模型名 gpt-6.1-sol，并通过 service_tier: "ultrafast" 选择档位。

「Near-Astra intelligence at up to 8x faster speeds than Sol Standard」

社区公告给出的 API 价为每百万输入 token 12 美元、输出 60 美元，并称约为 Astra 成本的 1.2 倍。Codex 与 ChatGPT Work 侧，访问面向 Pro 500、符合条件的按量企业方案，以及基于额度的 Edu 方案；企业管理员需开通。公告称 Ultrafast 覆盖所有支持区域，并支持美欧数据驻留；同时为 GPT-6.1 Sol Fast 与 GPT-6 Luna Fast 增加了欧盟数据驻留。

同一天，AWS「What's New」宣布 Amazon Bedrock 上的 OpenAI GPT-6.1 Sol 亦支持 Ultrafast，面向实时编程助手、交互式智能体等对延迟敏感的负载，可在 Bedrock 控制台或 API 启用。第三方整理稿还对比了缓存与长上下文价差，并提醒工作流其他环节仍可能成为瓶颈。本稿数字以 OpenAI 社区公告与 AWS 官方为准。
