OpenAI 发布 GPT-6.1 Terra：主打电脑操作与视觉推理，API 价格比 GPT-5.6 Terra 低一半

2026-10-26 · OpenAI · OpenAI API Changelog · DailyAI

OpenAI 于 2026 年 10 月 26 日发布 GPT-6.1 Terra，定位为兼顾细致视觉推理、精确电脑操作与更自然写作的高效模型，面向起草方案、读懂技术图纸、填写表单、剪辑视频等日常办公任务。OpenAI 称其标准 API 价格比 GPT-5.6 Terra 和 GPT-6.1 Sol 低 50%；DailyAI 按价目表转述为每百万输入/输出 token 1 美元/5 美元。

OpenAI 称其标准 API 价格比 GPT-5.6 Terra 和 GPT-6.1 Sol 低 50%

OpenAI 自报的测试结果：在电脑操作基准 Agents’ Last Exam 上，中等推理强度下比 GPT-5.6 Terra 高 15 个百分点、成本约三分之一，并与 GPT-6 Astra 持平而每 token 价格仅其十分之一；完成任务速度比 GPT-6 Astra 与 GPT-6.1 Sol 快三倍以上。Terminal-Bench 4.0 最高推理强度下解决 50.3% 的任务，GPT-5.6 Terra 公布成绩为 21.5%。内部易错提示集上，低推理强度错误率由 53.6% 降至 16.7%。

OpenAI 称 GPT-6.1 Terra 在其准备度框架（Preparedness Framework）下达到网络安全「Critical」阈值，并沿用为 GPT-6 Astra 开发的防护措施。模型已在 ChatGPT Work 与 Codex 中推出，并通过 API 以 gpt-6.1-terra 提供；最复杂的编程任务，OpenAI 仍建议使用 GPT-6.1 Sol 与 GPT-6 Astra。
