DeepSeek 发布 V4.1-Flash-1017：称基准更强、任务更快、输出更短；权重上线 Hugging Face，并开放 Search & Fetch API

2026-10-17 · DeepSeek API Docs · Hugging Face

DeepSeek 在 API 文档「news261017」页面宣布推出 DeepSeek-V4.1-Flash-1017，称相对上一版在基准表现、任务完成速度与输出长度上实现帕累托改进，并已在官网、应用与 API 上线。文档建议将 DeepSeek Harness 升级至 v0.2.1-rc.1 或更新版本，以获得与新模型的最佳配合；模型亦针对 Tencent CodeBuddy、WorkBuddy 等场景做了优化说明。

「公司称新版在端到端项目开发上用带自我反馈的强化学习改进表现，并同步开放权重。」

同日，DeepSeek 宣布开放基于自研搜索引擎的 Search 与 Fetch API，定价为每个端点每千次调用 0.75 美元；文档称通过 DeepSeek Harness、Claude Code、Codex 等服务端工具发起的 Search & Fetch 对 DeepSeek API 用户目前免费，自 2026 年 10 月 31 日 16:00 UTC 起计费。开放权重已上线 Hugging Face（deepseek-ai/DeepSeek-V4.1-Flash-1017）与 ModelScope。性能与成本对比图为 DeepSeek 自述，第三方独立复现情况本稿未核对。
