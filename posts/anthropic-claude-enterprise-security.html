Anthropic：Claude Enterprise 上线安全中心（beta）、推理钩子全面可用，并集中管理与防影子 IT 等管控

2026-11-05 · Anthropic / Claude

Anthropic 在 Claude 产品文档中介绍 Claude Enterprise 新一批安全与管理能力：安全中心（beta）在组织设置中汇总聊天、Cowork 与 Claude Code 的配置，并与 Anthropic 推荐配置对照；可下载报告供审计相关方查阅，文中明确安全中心是基于推荐的指导，不是任何法律或标准的认证。

推理钩子现已全面可用：提示钩子与工具调用前钩子把检查接到企业既有数据安全工具

推理钩子（inference hooks）现已全面可用：提示钩子把支持产品中的提示送往企业数据安全工具检查；工具调用前钩子则在工具执行前做检查，以便沿用既有 DLP 与安全策略。集中管理（beta）为母组织提供 admin.claude.com 控制台，可统一处理 SSO、SCIM、域名验证、组别与 Compliance API 密钥等公司级设置，并支持连接多个身份提供商。

访问控制方面，可通过 Admin API 一次性签出成员全部会话（不影响 API 密钥与已运行云会话）；企业管理员可自助维护 IP 允许列表；还可在受管电脑的 Claude Desktop 上阻止个人或其他外部 Claude 账号，以降低影子 IT。另有 Endpoint Detection and Response（EDR）集成（beta）：在本机 Cowork / unified Claude 虚拟机内运行组织传感器（检测模式，上报而不阻断），覆盖用户电脑上的虚拟机而非云端会话。
