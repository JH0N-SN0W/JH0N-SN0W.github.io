模型与产品

Meta：用 Muse Wonder 训练的专用模型上线 Muse 与 Meta AI；Active Memory 关键上下文正确使用率 90%（对照 76%），Active Focus 在突发阻碍下完成率提升 67%

2026-11-06 · Meta AI Research

Meta AI Research 于 2026 年 11 月 6 日发文称，继数周前推出面向复杂个人与专业代理任务的 Muse Wonder 系列之后，公司正将「用 Muse Wonder 训练的专用版现有模型」推送给 Muse 与 Meta AI 用户，把部分前沿能力带到更广的用户群。文中给出的 Personal Superintelligence Index 显示，当前 Muse 模型得分 47%，对照此前模型为 38%。

Active Memory 评测：当前 Muse 模型在 90% 的任务上正确使用关键上下文，对照此前模型为 76%

专用模型同步引入 Active Memory 与 Active Focus。Active Memory 旨在记住关键信息、识别较早内容何时重新相关，并区分临时与长期、仍有效与已过时信息；Meta 称 Muse 上忘记目标所必需关键信息的情况减少约 2.4 倍。内部 Active Memory 评测中，当前模型在 90% 的任务上正确使用关键上下文，对照此前模型为 76%。

Active Focus 则训练模型在遇到现实瓶颈时继续推进目标——更努力尝试、恢复或另寻路径。Meta 称 Muse 上在突发问题场景中完成日常任务的表现提升 67%。文中还提到多任务、自主推进与实时协作之间的取舍，以及在任务中途接受纠正而不迷失。Meta AI 侧则强调拆解复杂问题、追问更准、跟得上对话转向。本稿数字均出自 Meta 官方博文的自评指标。
