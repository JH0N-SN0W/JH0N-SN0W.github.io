模型与产品

OpenAI 宣布 GPT-Live-1.1 已在 API 中提供：可用模型代号 gpt-live-1.1 构建语音代理；并推出新的 Standby 配置，在 WebRTC 通话保持接通、推理暂停时按每分钟 0.02 美元计费，活动时段为每分钟 0.05 美元；公司称该模型自 2026 年 10 月 15 日起已为 ChatGPT Plus 与 Pro 的语音功能提供支持

2026-11-20 · OpenAI

OpenAI 开发者社区「Announcements」栏目在 2026 年 11 月 20 日由 @sps 发帖宣布：GPT-Live-1.1 现已在 API 中提供，开发者可用它构建在不同语言中口音更自然、更一致的语音代理，并更准确地理解字母和数字等细节，更可靠地遵循指令并完成任务。该帖写明，GPT-Live-1.1 自 2026 年 10 月 15 日起已为 ChatGPT Plus 与 Pro 的语音功能提供支持，现在可以用模型代号 gpt-live-1.1 将其用于开发者自己的应用。帖文并称，它能够在说话的同时倾听，并把复杂工作流委托给开发者选择的后端模型，而不打断对话节奏。

GPT-Live-1.1 自 10 月 15 日起已为 ChatGPT Plus 与 Pro 的语音功能提供支持。现在你可以用模型代号 gpt-live-1.1，把它用到自己的应用里。

同一篇公告介绍了名为 Standby 的新 GPT-Live API 配置，适用于 GPT-Live-1 与 GPT-Live-1.1。开发者可把空闲超时设为 5 至 60 秒；在这段静音之后，模型会暂时暂停推理，同时 WebRTC 通话保持接通，当有人再次开口时对话恢复。公告写明，Standby 按每分钟 0.02 美元计费，相比标准活动费率每分钟 0.05 美元；后端模型与工具用量另行计费。OpenAI API 文档中的 GPT-Live-1.1 模型页与上述费率一致，并写明该模型是面向多语种对话的全双工语音模型，能够在说话的同时倾听；与 GPT-Live-1 相比，它转写语音更准确，并能在不同语言中保持更一致的口音与声音。计费方式为按时长计算语音会话，后端模型与工具用量另行计费；较低的 Standby 费率适用于 WebRTC 会话中推理暂停的时段。文档给出的模型代号为 gpt-live-1.1，支持的端点为 v1/live/sessions。

OpenAI Deployment Safety Hub 上的《GPT-Live-1.1 system card》写明，该系统卡最初发布于 2026 年 10 月 15 日；更新日志记载，2026 年 11 月 19 日新增了 GPT-Live-1 API 与 GPT-Live-1.1 API 在生产与合成语音安全表中的结果，并说明了如何评估这些 API 语音模型。系统卡称，GPT-Live-1.1 API 是 GPT-Live-1 API 的后继模型，在多语种语音、指令遵循和声音保真方面有改进；与前代一样，该 API 语音模型负责听和说，并可将需要更多推理的请求委托给开发者选择的后端模型，后端的防护措施适用于它所执行的工作。本站以 11 月 20 日的 API 上线公告为这则消息的日期，并同时注明该模型此前已用于 ChatGPT 语音。
