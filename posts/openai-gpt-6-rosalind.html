OpenAI 发布 GPT-6 Rosalind：生命科学推理加科学工具；受信访问；API 标识 gpt-6-rosalind；Research / Discovery 分档

2026-10-30 · OpenAI API Changelog / Help Center

OpenAI API Changelog 于 2026 年 10 月 30 日记：发布 GPT-6 Rosalind（模型标识语境下为 gpt-6-rosalind），面向复杂生命科学研究，结合专用生物推理与科学工具使用。访问面向经 Rosalind Research 受信访问（trusted-access）计划批准、供授权用户内部研究的机构。帮助中心《GPT-Rosalind for life sciences research》进一步说明：GPT-Rosalind 是生命科学研究模型家族，可协助证据综合、跨生物数据推理，并协调文献、数据库、内部系统与专科模型等工作流。

API 标识 gpt-6-rosalind；不在 Chat 页；Academic Plan 不含 API；Enterprise Admin Preview 两周默认关

Research 与 Discovery 为两档访问：各自模型范围与生物安全护栏不同；Discovery 获批不等于 Research，升至 Research 须额外审核。Rosalind Research 档含 GPT-6 Rosalind Research 与 GPT-5.5 Rosalind Research；Discovery 面向日常科学工作，使用既有 Rosalind 5.5 模型并配更严监控，不含上述 Research 模型。GPT-6 Rosalind Research 面向有限获批 Research 机构，可在 Work 与 Codex 使用，并在单独获批时经 API 使用；不在 Chat 标签页提供。

API 侧对获批组织使用标识 gpt-6-rosalind；对另一 Rosalind 模型的批准本身不自动授予本模型。Rosalind Academic Plan 不含 API 访问或 API 积分。Enterprise 工作区中，GPT-6 Rosalind Research 先进入为期两周的 Admin Preview，默认关闭；管理员可为获批 Research 用户开启并配置预览结束后的访问。既有 Research 批准不绕过 Admin Preview。购买订阅或加入工作区本身不会自动获得 GPT-Rosalind 访问。
