模型与产品

Anthropic 推出 Claude Fable 5.2 与 Claude Mythos 5.2：同一底层模型；Fable 广泛可用并带网络与生物安全护栏，Mythos 经核验计划申请；输出最高比 5.1 快约 30%，定价每百万 token 8 / 40 美元

2026-11-09 · Anthropic

Anthropic 于 2026 年 11 月 9 日宣布推出 Claude Fable 5.2 与 Claude Mythos 5.2，称二者针对最艰巨的技术挑战，并在编码、推理与视觉方面有所改进。公司写明：Claude Fable 与 Claude Mythos 是同一底层模型。Fable 带有较强的网络安全与生物学安全护栏，因此可向所有用户开放；在网络安全或生物医学研究中从事有益应用的机构，可通过近期扩大的生命科学核验计划（Life Sciences Verification Program）与网络核验计划（Cyber Verification Program）申请使用 Mythos。

它们生成输出的速度最高比 Claude Fable 5.1 与 Claude Mythos 5.1 快约 30%，定价为每百万输入 token 8 美元、每百万输出 token 40 美元

博文称，测试者认为 Fable 5.2 与 Mythos 5.2 比过去的 Fable 与 Mythos 沟通更清楚；输出最高比 5.1 快约 30%，定价低于此前，为每百万输入 token 8 美元、每百万输出 token 40 美元。二者另提供可选加速模式（fast mode），出词速度最高约 2.5 倍，定价为每百万输入 token 16 美元、每百万输出 token 80 美元。公司建议：对多数编码与知识任务，用户先从「最强日常主力」Claude Opus 5.5 起步，再按工作范围与复杂度上调至 Fable 或 Mythos，或下调至 Claude Sonnet 5.5、Claude Haiku 5.5。Fable 5.2 也可充当 Advisor（由 Haiku、Sonnet 或 Opus 向它求助）或 Orchestrator（把较简单任务委派给更小模型）。Fable 5.2 即日起在所有平台提供，包括 Amazon Web Services、Google Cloud 与 Microsoft Azure；开发者可在 Claude Platform 使用 claude-fable-5-2。

预发布测试中，Anthropic 称这些模型帮助工程师完成原先难以推进的软件迁移、从零设计了三款可工作的电子设备、解决了两项黑洞物理开放问题、在机器人评测上取得实质进展，并由约 1,000 个 Fable 5.2 代理在 30 小时内、以极少人工干预形式化了费马大定理证明（对照：未发布研究版首次形式化耗时 11 天；同样 1,000 代理设置下，Opus 5.5 在 18 小时内只完成约 26%）。基准表显示，在 FrontierCode 2.0 上，Fable 5.2 于 Xhigh 付出下得 49.1%，对照 Fable 5.1 的 32.4%（Xhigh）、Opus 5.5 的 45.5%、GPT-6 Astra 的 42.8%、Gemini 4 Carbon 的 41.1%（Medium effort）。公司称 High 付出下 Fable 5.2 得分约与 Opus 5.5 的最佳成绩持平（45.3% 对 45.5%），而每任务成本大约减半。

安全方面，Anthropic 称对底层模型做了广泛预发布安全测试，认为高风险场景下的错位风险仍然较低，多数对齐指标表现不低于近期模型；Fable 5.2 的网络与生物护栏与 5.1 同样稳健，但不必要拦截更少——早期测试中拦截约比 Fable 5.1 少 55%（网络约少 60%，生物约少 40%），并称实施了迄今最强的蒸馏攻击防护，使蒸馏者收获的数据减少 90% 至 99%。完整细节见《Claude Fable 5.2 and Mythos 5.2 System Card》。企业侧的 Enterprise Frontier Safeguards 现处于私有测试，可在客户自有基础设施上对提示与回复做自动安全监测，并与零数据保留兼容。
