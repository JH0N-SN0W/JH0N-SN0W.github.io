OpenAI：ChatGPT Enterprise 登陆 AWS Marketplace；企业可用既有 AWS 采购与账单关系购买和管理，符合条件的支出可计入 AWS 承诺额度；含 ChatGPT、ChatGPT Work、Codex 与 dots

2026-11-09 · OpenAI

OpenAI 于 2026 年 11 月 9 日宣布，ChatGPT Enterprise 即日起可通过 AWS Marketplace 购买。公司称，该上架方式让组织能用既有的 AWS 采购与账单关系发现、购买和管理 ChatGPT Enterprise，并把符合条件的支出计入其 AWS 承诺额度。文中写道，每周有超过 12 亿人使用 ChatGPT；ChatGPT Enterprise 把这一熟悉体验带到工作场景，涵盖 ChatGPT、ChatGPT Work、Codex 与 dots。经由 AWS Marketplace 购买的客户，可获得与直接向 OpenAI 购买相同的模型、功能与特性，新功能也将同步上线。

组织可以用既有的 AWS 采购与账单关系发现、购买和管理 ChatGPT Enterprise，并把符合条件的支出计入其 AWS 承诺额度

OpenAI 称，这些产品与 Amazon Bedrock 中已提供的 OpenAI 模型形成互补：开发者可在 Bedrock 上用 OpenAI 模型构建应用与代理，业务团队则在日常工作中使用 ChatGPT Enterprise，组织可按负载与治理要求选择路径。OpenAI 云合作管理总监 Chris Grusz 表示：「企业越来越同时依赖 AWS 与 OpenAI 把 AI 投入工作，我们的合作就是让这一组合对他们更强。共同客户现在可以通过他们已经信任的云服务商，把 ChatGPT 带给自己的团队。」Sophos 首席技术官 John Peterson 则称，能通过单一渠道购买并运用既有 AWS 承诺，「去掉了常常拖慢企业 AI 采用的摩擦」。符合条件的客户还可通过 AWS Marketplace 使用 ChatGPT for Healthcare 与 ChatGPT for Financial Services。OpenAI 建议联系 OpenAI 或 AWS 客户团队确认资格并开始使用。
