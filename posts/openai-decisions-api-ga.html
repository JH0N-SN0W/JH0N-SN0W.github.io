OpenAI Decisions API 正式 GA：基于 GPT-6 Luna，有界答案，称可比 Responses API 快约 10 倍

2026-10-22 · OpenAI · OpenAI Developers

OpenAI 10 月 22 日宣布 Decisions API 正式一般可用（GA）。官方称该接口基于 GPT-6 Luna，面向分类、路由、下一步动作等「有界答案」问题，处理文本、图像与结构化输入，并称可比经 Responses API 调用 GPT-6 Luna「快约 10 倍」。开发者文档写明当前仅支持模型 gpt-6-luna，请求发往 POST /v1/decisions。

自公开 beta 以来，官方称新增提示缓存（prompt caching）、原生 JSON 输入、问题指令中可附图像、每请求最多 400 道题（此前 beta 为 200）、美欧推理驻留（US/EU residency），以及与 GPT-Live 的原生集成等。答案类型包括 predicate（概率）、choice（固定选项）、score（按量级打分）。

官方称可比经 Responses API 调用 GPT-6 Luna「快约 10 倍」。

定价方面，OpenAI 称 Decisions API 输入约每百万 token 0.10 美元，缓存命中输入约 0.01 美元，不收取输出 token 费用。区域处理与长上下文等溢价按适用条款执行；符合条件的客户可使用 Zero Data Retention。Box、Datadog、Ramp、Sierra、Speak 等客户在公告中给出了各自评测中的延迟或成本对比，均为对方自述。
