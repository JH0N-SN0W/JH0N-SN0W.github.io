OpenAI 将收购 Pierre Computer Company：强化 Codex 的代码浏览、Diff 审阅与 Git 工作流工具

2026-11-04 · OpenAI

OpenAI 于 2026 年 11 月 4 日宣布将收购 Pierre Computer Company, Inc.（Pierre）。Pierre 开发 Code Storage 及一系列开源开发者工具；OpenAI 称，若你已在 Codex 应用中浏览文件或审阅改动，便已用过 Pierre 的 Trees 与 Diffs 库。收购旨在把开发者熟悉的 Git 工作流，进一步适配编码智能体并行协作的方式。

把智能体时代的 Git 工作流，做到从开分支到部署的整条链路

官方介绍，Trees 便于快速导航项目文件，Diffs 便于查看变更；Diffs 的 Edit 模式可在发现问题时直接改行。Pierre 近期还发布了 Highlights 语法高亮器，可在开发者键入或智能体流式输出代码时高速更新。同一团队亦设计了 Code Storage 的 API，使应用能以 Git 方式存储代码并追踪历史。

OpenAI 表示交割完成后希望推进行业源代码控制能力，并把 Code Storage 的功能逐步纳入 Codex；Pierre 开源项目将继续开源并由其贡献。收购尚须监管审批等惯常交割条件；交割前双方仍保持独立运营，客户在交割后可继续使用 Code Storage。
