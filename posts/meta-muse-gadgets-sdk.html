Meta 开源 Muse Gadgets SDK，面向 DIY 智能体硬件

2026-10-02 · Unite.AI

Unite.AI 2026 年 10 月 2 日报道，Meta 开源了 Muse Gadgets 的固件与设备 SDK，便于创客把 Muse AI 智能体接到显示屏、按键、传感器与执行器等 DIY 硬件；同时推出 Muse Home Link——一款 USB-C 家用联网设备，在供应期内对美国 Muse 订阅用户免费提供。

「Announcing Muse Gadgets, an open source ESP32 firmware and Linux sdk so that you can make hardware devices that work with Muse.」

Nat Friedman 在 X 上宣布该计划，并引导开发者到 Muse Gadgets 页面获取 API token、把编码智能体指向 GitHub 仓库 facebookincubator/muse-gadget-sdk（Apache 2.0）。仓库含 esp32、linux 与 skills 目录：ESP32 SDK 可接屏幕、音频与传感器；Linux SDK 可将闲置树莓派或 Linux 主机变成 Muse 配件，示例包括系统管理与 Home Assistant。配对需 SDK token，并在移动端 Muse 应用开启开发者模式后于「设置 › 设备」中连接。

Friedman 称已生产一批 5000 台 Home Link，预计数周内发货，代码亦开源；设备可让 Muse 与电视、音箱及暴露 HTTPS/本地 HTTP API 的智能家居对话。页面还列出社区项目思路（圆屏 ESP32-S3、E Ink 终端、HDMI 电视棒等），并提醒第三方硬件由其他公司制造销售，Meta 不作背书。
