Meta 发布开放权重模型 Muse Spark Open：8160 亿参数、百万 token 上下文，可在两台 Mac Studio 上本地运行

2026-10-15 · Meta AI Research · TechCrunch

Meta AI Research 10 月 15 日公开发布 Muse Spark Open 的模型权重，称其为迄今能力最强的美国开放权重模型。该模型原生多模态，总参数 8160 亿、激活参数 420 亿，上下文窗口 100 万 token，主打编码与智能体任务，Meta 称其擅长长周期任务、复杂软件工程与多步推理。Meta 还称，它是同级别中第一个能借助最新 MLX 框架、在两台搭载 M5 Ultra 的 Apple Mac Studio 上于桌面本地运行的模型：每台 Mac Studio 的集成 GPU 最多可使用 512 GB 统一内存，两台合起来就能装下整个模型。

「每台 Mac Studio 的集成 GPU 最多可使用 512 GB 统一内存，两台合起来就能装下整个模型。」

获取方式方面，模型即日起可通过 Baseten、Fireworks AI、Groq、Modal、Nebius、OpenRouter 与 Together AI 等 API 平台调用，权重可在 Amazon SageMaker AI、Google Cloud Model Garden、Hugging Face 与 Microsoft Foundry Models 下载，并支持 SGLang、vLLM、TensorRT-LLM、Hugging Face Transformers、MLX、llama.cpp 与 Unsloth 等推理引擎。Meta 称，团队用自家编码终端 Muse Code 搭配该模型，完全在本地完成了为开源 Mastodon 客户端 Ice Cubes 提交 iOS 修改（含修复、新功能与完整构建），以及端到端操作 DaVinci Resolve 逐帧挑选并竖屏裁剪素材等测试。

许可方面，权重以 Muse Model License 发布，附有限的商业条款，Meta 称这允许许多开发者免费使用。安全方面，Meta 称开放权重版本做了额外的安全后训练，并按其 Meta Superintelligence Scaling Framework 完成评估、达到发布门槛，完整评估报告「即将发布」。TechCrunch 援引 Engadget 称，本地运行至少需要约 1TB 内存；文中的性能对比为 Meta 自行公布的评测结果。
