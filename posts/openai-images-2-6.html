OpenAI 推出 Images 2.6：生成提速约 50%，支持 GIF，API 提供 Flare 与 Sunburst

2026-11-04 · OpenAI

OpenAI 于 2026 年 11 月 4 日宣布 Images 2.6 在 ChatGPT、Codex 与 API 全球各档位上线。公司称生成速度约提升 50%，并支持 GIF 动画。API 提供 GPT-Image-2.6 Flare 与 Sunburst；Flare 在低质量设置下最快约 6 秒出图。

生成速度约提升 50%，并支持 GIF 动画

API 新增图像标注（markup）、SVG 导出与复杂度参数。文中称人们每周在 ChatGPT、Codex 与 API 上共创建约 40 亿张图片。
