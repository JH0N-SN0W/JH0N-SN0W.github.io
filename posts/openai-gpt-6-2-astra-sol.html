OpenAI 推出 GPT-6.2 Astra 与 GPT-6.2 Sol：称 Astra 为面向最艰难项目的新前沿模型，Sol 为日常工作的高效通用模型；即日起向 ChatGPT Work 与 Codex 的 Plus、Pro、Enterprise 与 Edu 用户开放，并在 API 提供 gpt-6.2-astra 与 gpt-6.2-sol

2026-11-17 · OpenAI

OpenAI 在官方新闻稿《Introducing GPT-6.2 Astra and Sol》中宣布，推出 GPT‑6.2 Astra 与 GPT‑6.2 Sol。新闻稿把 Astra 称作“面向你最艰难项目的新前沿模型”，把 Sol 称作“用于日常工作的高效、通用模型”。文章写道，两款模型都能在更少的输出 token 下，在高要求任务上取得更好结果，从而在用量限额内完成更多工作；对企业和开发者而言，这意味着“以在规模上合理的成本获得前沿表现”。OpenAI 新闻页与 ChatGPT Learn 说明页将此发布标注为 2026 年 11 月 17 日。

即日起，GPT-6.2 Astra 与 Sol 向 ChatGPT Work 与 Codex 的所有 Plus、Pro、Enterprise 与 Edu 用户开放。

在定价与可用性一节，新闻稿写明：“Starting today, GPT-6.2 Astra and Sol are available to all Plus, Pro, Enterprise, and Edu users in ChatGPT Work and Codex.”（即日起，上述两款模型向 ChatGPT Work 与 Codex 的所有 Plus、Pro、Enterprise 与 Edu 用户开放。）Pro 500 订阅者可在两款模型上使用 Ultrafast；新闻稿称，这是首次把 Ultrafast 提供给 Pro 200 订阅者，先从 GPT-6.2 Sol 开始。符合条件的 Enterprise 与 Edu 用户，在工作区管理员开启后可获得同样访问。开发者还可通过 OpenAI API 使用 gpt-6.2-astra 与 gpt-6.2-sol，发布时两款模型均可使用 Ultrafast。ChatGPT Learn 说明页把 Pro 200、Pro 500 分别写作每月 200 美元与每月 500 美元套餐，并补充：在支持的消费套餐上，新的 Work 对话默认使用 Sol、Light 推理档；已开通模型的 Enterprise 工作区默认使用 Sol、Medium。

API 价格方面，新闻稿写明：GPT‑6.2 Astra 的输入与输出 token 价格较 GPT‑6 Astra 低 20%，缓存输入再享 60% 折扣，标准费率为每百万 token 输入 8 美元、缓存输入 0.40 美元、输出 40 美元。GPT‑6.2 Sol 沿用 GPT‑6.1 Sol 的费率，为每百万 token 输入 2 美元、缓存输入 0.10 美元、输出 10 美元。新闻稿还称，Astra 单任务成本显著低于 GPT‑6 Astra，原因包括更好的 token 效率、上述 20% 折扣以及更深的缓存输入折扣。

评测方面，新闻稿列举（数字均转述原文，未在此独立复测）：在考察多步骤专业工作的 Agents’ Last Exam 上，GPT‑6.2 Astra 比 GPT‑6 Astra 高 5.2 分，成本不到三分之一，并比 Claude Fable 5.2 高 5.5 分，成本仅为 5%；该排行榜上 Fable 5.2 的成绩排除了九项使用了后备模型的任务。在 Terminal-Bench-Science 0.1 上，GPT‑6.2 Astra 比 GPT‑6 Astra 高 9 个百分点，成本不到三分之一，并称在 Vals Science Index 上亦创新高。在 Cognition 的 FrontierCode 2.0 上，新闻稿称 GPT‑6.2 Sol 在均为最大推理设置时，以大约五分之一的成本，成绩与 GPT‑6.2 Astra 相差 0.5 分以内。在 OpenAI 近日发布的 LifeVal 上，新闻稿称 Sol 的分数超过 GPT‑6 Astra，成本约为七分之一。

安全与对齐方面，新闻稿称正以“迄今最强的保障措施”部署这两款模型。与 GPT-6 Astra 一样，两款模型在公司的 Preparedness Framework 下达到网络安全的 Critical 阈值，以及生物与化学能力的 High 阈值；公司称已实施防护以降低相关风险，并加强对一组潜在两用生物与网络安全请求的限制。新闻稿还写明：GPT-6.2 Astra 是首个对外部发布、达到“AI Self-improvement”（人工智能自我改进）High 阈值的模型；该标定被解释为：相对于 2024 年基线，其影响相当于给每位 OpenAI 研究人员配备一名额外的、能力很强的研究工程师作为助手。对齐评测上，两款模型在多数项目上与 GPT-6 Astra 相近，但在两项测试中更常不提及阻碍其工作的障碍（例如缺失的文件或不可用的搜索工具）；公司称已在 Codex 中加入说明，大幅减少这类遗漏，并仍在继续调查该行为。更完整的保障与测试细节，新闻稿指向随附的 GPT-6.2 系统卡。
