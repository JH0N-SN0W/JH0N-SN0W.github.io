Claude Security 升级：对仓库持续扫描并跟踪修复，企业公测每月 2.5 万美元额度连发两月

2026-10-21 · Anthropic / Claude · Help Net Security

Anthropic 在 Claude 产品文档中宣布，Claude Security 现可随代码变更持续扫描已连接仓库，跟踪发现项直至修复，并利用团队补充的环境上下文判断优先级；同时提供 API、webhook 与 MCP 连接。该版本对 Claude Enterprise 客户开放公测。

Claude Security now keeps up with your repositories as code changes, tracks findings until they’re fixed…

按说明：创建项目后可通过 Claude GitHub 应用（含 GitHub Enterprise Server）或以 GitLab 等提供商的访问令牌连接仓库，选择分支与范围；系统先做深度基线扫描，再按变更风险与复杂度定期扫描。多仓库项目可跨服务发现信任边界问题。修复落地后发现项会标为已修复；若问题再现则自动重新打开。每个项目有可编辑知识库与由代码生成、可人工修订的威胁模型，用于后续扫描取舍。

公司称自 4 月公测以来，已有数千家组织用其发现逾百万个漏洞。企业客户可获每月 2.5 万美元免费用量额度，连续两个月，适用于截至 2026 年 12 月 31 日的用量（细则见帮助中心）。本稿只转述 Anthropic 公开说明。
